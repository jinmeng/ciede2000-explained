# CIEDE2000 色差公式 · 大白话交互图解

一个**自包含的单文件交互科普页**（原生 JS、无外部请求），解释工业色差标准 CIEDE2000（ΔE00）的原理。

**在线阅读：<https://windrise-watersurge.github.io/ciede2000-explained/>**

## 里面有四个可以玩的演示

1. **a\*–b\* 颜色地图**：拖动取色点，实时读出 L\*/a\*/b\*/彩度 C\*/色相角 h；
2. **同距不同感**：三对"直线距离都是 10 分"的颜色，人眼感受天差地别；
3. **等色差椭圆动画**（核心）：拖动中心色，看 ΔE00=8 的等差圈在灰区收紧、艳区放大、蓝区被"掰歪"——这正是 CIEDE2000 对人眼视觉容差的建模；
4. **公式六步流水线 + 四公式打分器**：G 因子、三个色差分量、SL/SC/SH、T、RT 旋转项每步数字实时可看；CIE76 / CIE94 / CMC / CIEDE2000 同台对比。

## 可信度

- 页面内置的 CIEDE2000 实现已通过 Sharma, Wu & Dalal (2005) 发表的 **34 对官方测试数据逐位校验**（误差 < 0.00005）；
- 页脚列出全部事实出处：Sharma 2005（doi:10.1002/col.20070）、CIE 142:2001、Luo 2002 等。

## 使用

单文件即 `index.html`，双击本地打开或直接部署到任意静态托管均可。
